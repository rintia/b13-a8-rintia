📚 Borrowly – Book Borrowing System
🌐 Live URL

https://b13-a8-rintia.vercel.app

🎯 Project Purpose

Borrowly is a simple and user-friendly book borrowing web application where users can browse books, filter by category, search by title, and borrow books easily. The system is designed to make book access fast, organized, and accessible online.

✨ Key Features
🔐 User Authentication (Sign up / Sign in / Google Sign-in)
📚 View all available books
🔎 Search books by title
🗂️ Filter books by category (Story, Tech, Science)
📖 Borrow books with validation
📱 Responsive UI (mobile + desktop)
🎨 Animated UI sections using Animate.css
⚡ Dynamic routing for book details page
☁️ Deployed on Vercel
📦 NPM Packages Used
Next.js – React framework for full-stack app
React – UI library
Tailwind CSS – Styling framework
React Toastify – Toast notifications
Animate.css – UI animations
HeroUI (@heroui/react) – UI components
MongoDB – Database (used in backend)
